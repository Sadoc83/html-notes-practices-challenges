# 🚀 Mi Laboratorio de HTML5

¡Hola! Este es mi repositorio personal dedicado a la práctica, experimentación y documentación del desarrollo web desde sus bases. Aquí archivo mis notas teóricas y los retos prácticos que voy resolviendo.

## 🛠️ Herramientas
* **Editor:** Visual Studio Code
* **Control de Versiones:** Git & GitHub

## 📁 Estructura del Repositorio
* `📂 01-notas/`: Resúmenes teóricos en formato Markdown.
* `📂 02-tareas/`: Proyectos y ejercicios prácticos en HTML puro.

## 📈 Mi Progreso (Checklist)
- [ ] Estructura básica de un documento HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- [ ] Etiquetas de texto y jerarquía (`<h1>` a `<h6>`, `<p>`, `<strong>`)
- [ ] Enlaces y navegación (`<a>`, rutas relativas y absolutas)
- [ ] Listas y Tablas (`<ul>`, `<ol>`, `<table>`)
- [ ] Formularios y validaciones nativas (`<input>`, `<form>`)
- [ ] Elementos semánticos avanzados (`<article>`, `<section>`, `<aside>`)
